WordProject

  • Click the download tab on the site and download the whole Bible in that language. For example, if you are in Portuguese, click download, and choose portuguese in the index page that opens. After you finish downloading, use 7Zip or another program [search for a free zip compressing/expand program] and unzip [uncompress - expand] the directory. You should have a directory named 'po', for Portuguese, or other names for whatever language you are downloading. Place this directory anywhere in your computer... [desktop, for example] or if you are using a smartphone, on the memory card of the phone. After, you open the directory and find a file named index.htm. Double click to open the file. The file should open in your browser and will look like any other web page. Navigate through it and use it as a Bible. Because this is a web page and compatible with any computer, smartphone it should work almost anywhere. Enjoy Wordproject to read and study the Word of God anywhere.
