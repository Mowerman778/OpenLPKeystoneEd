1. Sunday in six steps

  1. Open last week's service or start a new one: Ctrl+O / Ctrl+N.
  2. Add items: find a song, Bible passage or presentation in the Library, select it and press + to add it to the Service.
  3. Put them in order: drag them in the Service list, or use Page Up / Page Down.
  4. Save: Ctrl+S. The saved file (.osz) holds everything, including videos and presentations, so it can be opened on another computer.
  5. Before the service: blank the screen with . (full stop) so nothing shows by accident.
  6. During the service: select the item in the Service list and press Enter to send it live, then ↓ / ↑ to move through the slides. → jumps to the next service item.
Tip: look at a slide in Preview first; nothing there is seen by the congregation. Only Live goes to the projector.

Lost a panel? Use the View menu, or the function keys: F8 Library, F9 Service, F10 Themes, F11 Preview, F12 Live. Pressing a key twice hides and shows the panel again, which also puts it back if it went astray.

4. Live: show, blank and hide

The buttons above the Live panel do the same as ., T, D and Space.

  • Blank (.) is the safe choice between items: black screen, nothing else.
  • Theme (T) keeps the background up while the words go away, which looks smoother.
  • Desktop (D/Esc) takes the projector output away completely.
  • View → Hide Projector Window (Ctrl+F12) is for you, not the congregation: when the projector window covers the Live panel or another window on your screen, this tucks it away. Blanking and showing still work while it is hidden. Press it again to bring it back.

5. Songs

  • Searching: type part of the title or words. The drop-down by the search box chooses titles, lyrics, authors and so on.
  • Editing: double-click a song. Each part (verse, chorus…) is its own slide. The order box, e.g. V1 C1 V2 C1 B1 C1, sets the order it plays in, so a chorus is only typed once.
  • SongSelect (CCLI): File → Import → CCLI SongSelect. Search, or open SongSelect in your browser; songs you download there are imported automatically.
  • Credits slide: songs can end with a slide showing the authors and copyright. Turn it on in Settings → Configure OpenLP → Songs.
Tip: don't type © in a song's copyright field. Keystone adds it itself, so you would see "© © 2022". Long copyright lines wrap onto a second line; if they don't fit, make the footer box taller in the theme (section 9).

6. Bibles

  • Type a reference such as John 3:16-18 or Ps 23 and press Enter.
  • Add a second Bible to show two versions side by side, e.g. English and Afrikaans.
  • Bibles use the theme set in Settings → Configure OpenLP → Bibles, so verses can look different from songs.

7. Presentations

  • Add PowerPoint (.pptx) or LibreOffice (.odp) files in the Presentations library, then add them to the service like anything else. PDFs work too.
  • Keystone shows them with LibreOffice Impress (or PowerPoint if it is installed and chosen in settings).
  • The first presentation is slow to open: LibreOffice has to start. Presentations with heavy graphics or animations take longer to load. Send the presentation live once before the service starts and the wait is out of the way.
  • Move through the slides with the same keys as songs. Animations play one click at a time.
Videos inside a presentation: LibreOffice can crash or show a garbled picture when it plays them. When you add a presentation that has videos, Keystone warns you and says which slides. Take the videos out of the presentation and use the Video Trigger Manager instead (next section).

8. Videos on presentation slides

Keystone plays the video itself, full screen over the slide, which is reliable. Each slide can have up to ten clips.

  1. Delete the video from the presentation and save it. Keep the video file somewhere handy.
  2. Add the presentation to the service. In the Service list, click the arrow next to it to see its slides.
  3. Right-click the slide and choose Video Trigger Manager…
  4. Click Add video…, pick the file, give it a short description and drag its box to where the video should be on the slide.
  5. Tick Play as soon as the slide is shown if it should start by itself. Otherwise it waits for you.

During the service, the clip boxes appear over the slide in the Live panel (only you see them). Click a box to play that clip. When it ends, the slide is back on the screen, so the speaker can carry on.

Tip: the videos are saved inside the service file, so copying the .osz file to another computer takes them along.

9. Themes

  • Right-click a theme in the Themes panel and choose Edit Theme to open the Theme Manager. (Double-clicking a theme makes it the default theme instead.)
  • The two boxes on the preview are the main text and the footer (song title and copyright). Drag them to move them, drag the edges to resize them. Click Save.
  • Use the default position puts a box back where OpenLP would normally put it.
  • Font, size, colour, outline and shadow are set per box; the background (colour, gradient, picture or video) on its own tab.
Tip: white text with a black outline or shadow stays readable on almost any background.

10. Layouts and monitors

  • The Layout box at the bottom right switches between arrangements of the panels: 1 Monitor Default, 2 Monitor Default and any you save yourself. Keystone remembers which one you use with one monitor and with two.
  • Changing a layout: View → Layout → Layout Setup Mode unlocks the panels. Drag them by their title bars, even onto a second monitor, then click Save or Save As New Layout… and Done.
  • In Setup Mode you can also put the Preview and Live slide lists above the picture or to its right.
  • No projector? View → Simulated Projector Mode shows the live output in a window laid out exactly as on an HD projector, for preparing at home.
  • Projector on the wrong screen? Settings → Configure OpenLP → Screens.

11. Updates, backups and help

WhereWhat
Help → Updates…Checks for a newer Keystone, shows what's new and installs it. Keystone closes (asking to save the service), updates itself and starts again. Windows asks for permission: click Yes. Tick the box to check once a day at start-up.
Help → Version History…Which version you have and what changed.
Help → Create Debug ReportMakes a folder of information to send when something goes wrong.
Help → Debug LoggingLeave this off unless asked to turn it on: it slows Keystone down.
Tools → Open Data Folder… Where your songs, Bibles and themes are kept. Copy this folder to a USB stick now and then as a backup (close Keystone first).

Keystone and the normal OpenLP can be installed on the same computer. They keep separate songs, Bibles and settings. The first time Keystone starts it offers to copy everything from OpenLP; after that, changes in one are not seen in the other. Don't run both at the same time.

12. When something goes wrong

ProblemTry this
Wrong thing on the screenPress . to blank at once, then sort it out in Preview.
The projector window covers the Live panelCtrl+F12 hides it; press it again to bring it back.
A panel has disappearedPress its function key twice (F11 Preview, F12 Live…) or choose your layout again in the Layout box.
Odd leftover pictures of panelsMinimise Keystone and restore it.
A presentation won't show or LibreOffice crashedSend it live again; Keystone restarts LibreOffice. If it has videos, use the Video Trigger Manager instead.
A video doesn't playCheck the file still exists (the Video Trigger Manager marks missing ones) and that VLC is installed.
Keystone is slowMake sure Help → Debug Logging is off.
Anything elseHelp → Create Debug Report and send the folder, with a note of what you were doing.
